统一候选证书到旧 F-ports：后端条件与全赋值投影审查
2026-10-28；只作逻辑审查，不运行实验，不修改求解器

0. 审查对象与结论
=================
本稿审查新 CAUSAL_FRONTIER_STRUCTURE/FEEDBACK/BARRIER/COMPOSITION 的候选
计划如何满足已有后端的确切前提。对照读取了：
  docs/RELATIONAL_FORGETTING_THEOREMS.zh.txt：B1–B5、C1、E1、E2；
  docs/FUTURE_PORT_THEOREMS.zh.txt：P1–P4、§6；
  docs/FUTURE_PORT_CERTIFICATE_BRIDGE.zh.txt：B3/B4；
  wmcheck/ra.py、ra_frontier.py、port_monitor.py、compiler.py、graph_solver.py。

审查结论：新二元候选计划与失败链展开可满足旧数学后端的条件；该后端不要求
事件引入次序保持 SB。必须保留的条件是固定全部候选、连续寿命、完整组覆盖、
唯一变量归属、恰一 RF 计数，以及所有监视器的联合摘要。

工程边界：现有 compile_frontier() 自己调用 recognize()，仅以 order 参数
安排按端点最大 rank 排序的组，并未提供外部协议证书和任意袋/组计划的入口。
RAInstance 也只有固定返回值或 None，尚无新 branch guard 前端。因此本稿是
数学后端的可组合性审查，不宣称现有函数已经实现新协议和新计划。

1. 首先固定编译输入的量词
=========================
I 包括原始事件、程序序、地址/写值、所用观测合同；C 是经语法检查的协议
合同/角色映射或给定证书。预处理在空查询下产生
  Gamma_I=(D_I,H_I,L_I,必要的常量与推导理由)，
  G_I=稀疏候选并图，pi_I=候选组与引入/退休的完整计划。
Gamma_I、G_I、pi_I 只由 (I,C) 决定；不读入完成 J 或临时查询 alpha。
本文不要求预处理求出全部语义公共 HB，只要求所有输出事实可靠。

对具体合法 J，可以令 gamma_J 记录该 J 所选来源的实际代号和未记录的返回
值。但 gamma_J 仅是正确性证明见证，不再参与选择 G_I 或 pi_I。
尤其 F-ports 的 I_t/O_t 是扫描全部静态候选组得到的端口，不能只扫描 J 的
已选 RF/CO；它们可以同时包括互不相容的候选，不能因此当作真实已选边。

2. 给定证书的编译合同
=====================
令 X_I 在协议过滤/guard 删边之前建立，包含输入原始候选 RF 位及所有同址
写对 CO 位。固定返回值输入可以只登记同值 RF；没有记录返回值的输入登记
全部同址候选，随后由输入 guard 排除的位仍作为 false 常量保留。

Phi_I(x) 为完整原始语义：每读恰一个允许来源，来源值满足固定值/允许值及
已记录分支；CO 每地址初始化最小严格总序；全部真实 SB/init；RA coherence。
若某个 branch guard 尚不能归约为已证的逐读允许集合，就不能直接交给只认识
这些约束的后端。本轮 GPS 合同先由 F1 固定自己的索引，才将满/空 guard
归约为 peer 读的有限允许集合；这一证明义务不被 None 代替。

给定证书接口另有必要前提：固定返回值、允许值集合，以及已经证明可逐读化
的全部已观测 guard，必须精确转为来源允许限制并在域/常量层执行。每个保留
候选均满足这些限制，每个被排除的原始位保留 false。只有“D 是可靠 may-RF”
并不足够：它允许含有不合法的来源，而 RA 监视器本身不会识别任意程序 guard。
若固定值已直接与原 guard 矛盾，则返回有理由的恒假制品。一般多读联合 guard
不在本给定证书合同中；若另行编码，其状态/费用与投影必须单独证明。

给定可靠 Gamma_I、以及满足第 3 节条件的 pi_I，定义 A_I(x,y) 为接受路径
语言的支持编码；y 包含内部辅助变量，不包含被偷偷隐去的原始 CO/RF。

定理 BA1（全部赋值上的投影）。同一编译结果满足
  对所有 x∈{0,1}^{X_I}：Phi_I(x) iff 存在 y，使 A_I(x,y)。
此式包括所有不满足 one-hot、总序、guard 或 RA 公理的 x，不能只对已经
合法的 x 断言存在路径。若 Phi_I 无解，编译图没有接受路径，等价仍成立。

3. 逐项对接旧 B1–B5，而非只引用“图很窄”
=======================================
下列 B1–B5 的编号来自 RELATIONAL_FORGETTING_THEOREMS 第 B 节。

B1：事件袋寿命连续。
一般前沿计划使用固定候选图的实际过去边界 F_t；事件自首次引入到最后一个
候选邻接处理前连续保留。稳定写极大集合仅用于界定数量，不导致事件复活。
失败链计划先登记所有来源/SB 锚的延长寿命，再逐个引入真实失败读；每次
只保留当前及前一个链节点。末尾没有右锚时使用无语义虚拟处理位置，不添加
程序事件。根本条件是连续区间，与引入次序是否沿 SB 无关。

B2：一组的全部候选端点在同一个袋。
每个二元 RF 位的 true/false 替代项共享 (w,r)；每个 CO 位的两个方向共享
(u,v)。固定 Cov(L)、真实 SB、初始化边和一元 mark 亦逐组覆盖。
前沿布局在较晚端点出现时处理；失败链的锚和两端事先共存，再插入真实链。
不能把二元证明直接用于含全部来源的原子组；后者须另验其全部端点的袋覆盖。

B3：遗忘前所有可能关联都已处理。
last(e) 按所有替代项的端点计算，不能按某条已选执行计算。读的未来 RF
候选即使最终被选 false，也必须影响 last。失败链的每个读处理固定 RF、
逆 RF 和前/后 SB 后才退休。左右锚在全部登记关联结束前不退休。

B4：原始变量、真实边和事件测试全部覆盖。
每个 RF/CO 变量恰由一个选择组或常量入口拥有；每条完整路径在该位置
输出其正或负文字。每个事件首次参与组时安装 RA 监视器的两个 mark；
不能只在引入时检查冲突后删除测试，而须由 T 保留穿过其 mark 的历史路径。
纯失败链的规划缩边不是语义边，最终必须安装全部真实 SB。

B5：局部良构计数及最后检查。
二元 RF true 恰将其读的计数加一；固定 RF 也加一。计数只需 0/1/溢出，
溢出拒绝，最后关联组后要求为 1。即使读的 SB 前驱尚未引入，计数也仍可
从 0 开始；只要其所有 RF 候选在退休前处理即可。direct CO 不使用最终
successor 的入/出度计数，而由全局 g 无环保证总序，见下一节。

这五项是候选并图的条件，不是已选执行的条件。认证袋大小 K 后，有界联合
摘要的成本成立；袋检查通过本身不等于输入 SAT。

4. 稀疏 CO 没有隐去原始方向
==========================
对每个 L_I 已比较的写对，原始位在常量入口输出已证方向。对每个不可比
写对，保留其原始位的二元方向选择。令
  g=Cov(L_I) ∪ 所有被选中的未决方向。
把 g 无环作为整体约束；以 co=g+ 解释 RA。

引理 BA2。所有满足该约束的选择与扩张 L_I 的严格总 CO 一一对应，而且
每个原始 CO 位的真假恰为该总序的对应方向。
证明。有限偏序 L_I 的闭包由 Cov(L_I) 产生；每个剩余写对又有一个明确
所选方向。因此 g+ 比较每个不同写对。无环使它严格，闭包使它传递，故为
全序。反向取任意扩张 L_I 的全序，它决定全部未决方向，所有 g 边都在该
总序中；又已比较每对，所以 g+ 正好等于该总序。证毕。

一个已退休的写与未来写之间，若原始比较已由 L 证明，则它的变量早已作为
常量存在，g 中保留生成该方向所需的覆盖路径。若比较未定，原始二元组会
使相关端点活到该组处理完，不能先把它遗忘再自由选择方向。

本轮使用此 direct 证明，对应 CAUSAL_FRONTIER_STRUCTURE CF5 及
FUTURE_PORT_THEOREMS §5。旧 RELATIONAL_FORGETTING_THEOREMS D1/D3
是另一种 successor/Q 编码的投影，不应把 successor 的计数公式混入 direct。

5. 删除 RF、退休事件与查询身份
=============================
被证书排除的原始 RF 位显式赋 false；已证必选 RF 显式赋 true，并仍安装
真实 r 与 R=rf^{-1} 两种方向标签，不能只有查询标签而没有语义边。
未决定 RF 位的 true 替代项同时安装 r、R 并增加来源计数，false 不加边。

事件退休只删除活跃关系矩阵中的端点；原始文字及其变量编号仍在先前路径
边标签、注册表与支持索引中。将来假设一个很早的 RF 或 CO 位，是过滤不
相容标签路径，不需要把该事件重新引入关系接口。与常量冲突的查询会阻断
常量入口，从而立即没有接受路径。

一个变量已输出为常量或二元标签后，其所有有关历史选择仍通过联合状态
影响后缀合法性。因此“仅保存当前必然文字”不是该表示，逐位无条件支持
的集合也不足以代替路径语言。

6. 全局相关性：合并的是联合右同余
=================================
RA 用禁止语言 (s|r)+(r|c|R c+)*，其中 c 表示 g。g+ 给 CO，R c+ 给 FR；
因此这个语言恰检测 hb;eco? 自环。另一个监视器检测 g 无环。
所有真实 sb 与 sparse-init 均加入 s；不把布局次序作为 s 加入。

FUTURE_PORT_THEOREMS P1 把禁止闭合游走精确变成恰一个 mark 的闭合游走；
P2/P3 证明同层的联合 (普通可达 R、恰一 mark 路径 T、全部监视器、计数)
相同，才具有相同后缀语言。不能分别取两个历史各关系的并，也不能把 T;T
当作允许路径。各前缀实际取的标签保留在各自入路径。

一个接受路径逐层选择固定组的一项。归纳可重建同一个完整选择历史；合并
节点不会使这一历史的后缀变成另一个历史才能满足的后缀，因为 P3 是对任意
相同后缀选择的双向等价。于是接受路径形成一个全局一致 x，而不是每个变量
分别可行、但彼此无法同时满足的一组局部支持。

由此证明 BA1：若 Phi_I(x) 成立，可靠过滤保留其所有源、常量与 CO 方向，
按 x 选择各组后所有监视器接受，得到一条路径及编码扩展。反之若 A_I(x,y)
成立，支持编码给存在一条与完整 x 相容的接受路径；唯一归属保证其标签正好
是 x，来源计数和 BA2 保证良构，RA 监视器保证全部原始公理，所以 Phi_I(x)。

这里使用旧 P4 的接受路径投影，以及 RELATIONAL_FORGETTING_THEOREMS
E1/E2 的路径语言/支持编码。通用支持编码不是本轮新的理论贡献。

7. 两种观测各自的完整入口
=========================
入口 V（完整固定返回值）。Phi_I^V 要求每读值等于日志固定值，并满足给定
程序控制流；相同的二元编译满足
  对所有 x：Phi_I^V(x) iff 存在 y，A_I^V(x,y)。
缓冲模窗口内固定索引值会锁控制来源；数据区域的其他 RF/CO 仍可不唯一。

入口 B（仅分支，或部分返回值）。Phi_I^B 保留原允许值集合和所有已记录
guard。源写值决定该完成中实际返回值；不为整个输入先挑一个返回值。
在 F1 将自己的索引认证以后，peer guard 成为输入可计算的允许集合；被
guard 排除的原始候选保留 false 标签。相同证明给
  对所有 x：Phi_I^B(x) iff 存在 y，A_I^B(x,y)。
因此多代来源不同的 x 可以同时在一个编译物内，无需先枚举每一种返回值
再分别编译。该观测入口是未实现的明确扩展，不是旧 None 无条件接受分支。

若两个观测合同不同，Phi_I^V 和 Phi_I^B 本来就是不同公式，不应把某个模式
的多来源见证拿来声称另一个模式也有相同歧义。

8. 任意假设、撤销与更一般公式
=============================
令 alpha 是 X_I 上文字的合取（可包括矛盾文字），ell 是一个原始文字。BA1
直接推出
  SAT(Phi_I ∧ alpha ∧ ell) iff SAT(A_I ∧ alpha ∧ ell)。
编译物保持不变，改变/撤销 alpha 只重新筛选路径。原始每一极性有支持，
当且仅当携带它的边处于一条相容的初态到终态路径上。前后向扫描因而同时
给出全部支持、必然文字与无解判断。

RELATIONAL_FORGETTING_THEOREMS E2 的支持 CNF 在原始文字假设下，通过
不可达信息的单位传播检出无解或全部必然原始文字。这不扩展到任意辅助变量
决策的全局传播完备性。

投影等价本身对任意只含 X_I 的公式 F(X_I) 也保持可满足性：
  SAT(Phi_I∧F) iff SAT(A_I∧F)。
但任意布尔公式的交互可能要求额外求解；廉价单次支持扫描、纯 UP 完备性及
其复杂度不因此自动扩展到任意 F。本文主查询合同仅为文字部分赋值/合取。

9. 成本与实现的确切对应
=======================
对二元计划，每个事件袋最多 K 个事件，四状态 RA 与单状态 CO 给
  rho≤2(4K)^2+K^2=33K²，
活跃来源计数至多 K 个布尔位。由旧桥梁 B3/B4 与 P3 得
  S≤2^(33K²+K)，组数 M=O(KN)，
  图/原始标签/支持编码大小 O(|X_I|+KN S)。
构造时间为所有证书/候选/计划预处理 T_pre 加 O(|X_I|+KN S poly(K))。
本审查不重新证明协议预处理次数，详见 CAUSAL_FRONTIER_CONSTRUCTION。
N 包括全部失败读；|X_I| 可能二次增长，不因接口小而消失。

实际代码核对：
  - RARegistry 在 recognize 之前建立，既有原始 RF/CO 位不会随删域消失；
  - compile_frontier 把删 RF 写为负常量、必选 RF 为正常量，CO 常量同理；
  - direct 模式只加入 Cov(L) 和未决方向，避免物化稠密 H/L；
  - state=(全部监视器矩阵,全部局部计数)，按同层联合键合并；
  - plan_ports 扫描所有 alternatives 及初次出现的 tests，计算 last_in/out，
    不接受 alpha，也不读取某个补全；
  - GraphSolver 依据原始文字标签筛边，再做前/后向可达；
  - support_cnf 的辅助蕴含用来传播阻断，不要求用户对辅助变量决策。

现有 CNF 实现使用足够的单向不可达蕴含而非每个辅助结点完整双向定义；这
不会破坏全赋值投影：无路径时这些蕴含强制初态不可达而冲突；有路径时给
辅助变量赋真实不可达值即可满足。辅助赋值不必唯一，主合同只要求存在。

10. 失败链非 SB 布局的专门结论
===============================
FEEDBACK §6 先在骨架袋中持有左右 SB 锚及固定 RF 写锚，再插入读链。
即使右锚先引入，旧 B1–B5、P1–P3 都只检查边和候选处理计划，不检查运行时
调度。真实 SB 边可以指向此前已经引入的端点；若它与 RF/CO 一起形成非法
闭合游走，联合监视器仍会拒绝。标记在右锚初次出现时已加入，后来的回路
不会因右锚早引入而丢失。

不过不能把每条展开链的局部合法性取笛卡尔积；最终仍编译同一完整输入的
全部真实 SB/RF/CO。无语义超边、虚拟处理位置和骨架缩边只能用于安排袋。
所有原始失败读位和计数必须实际进入最终计划。若锚生命周期或完整候选覆盖
没有得到证明，便不能用 +2 展开界。

目前未发现上述已修订数学计划与旧后端的条件冲突。尚待实现的是新证书与
组计划适配接口，不是理论证明需要调用求解器取得某个 J 后再选布局。

11. 对 MAIN_CONTRACT §1–7 的第二次独立核对
========================================
本节针对 2026-10-28 的主定理合同逐项复核，避免正文强于支撑证明。

11.1 FULL 确实覆盖非法全赋值。
MAIN_CONTRACT §3 明写量词 x∈{0,1}^{X_I}，其反向不预设 x 合法：若
存在编码扩展，须先得到与整个 x 相容的接受路径，再由路径推出 x 合法。
逐类检查：违反删 RF=false、固定 RF=true 或已定 CO 的 x 阻断常量入口；
零个或多个来源分别被最终恰一检查、溢出检查拒绝；非总序 CO 要么违背已定
文字，要么令 g 成环；剩余不满足 RA 的选择由完整联合监视器拒绝；不满足
已证明逐读化 guard 的来源已被固定为 false。因此没有把“对合法 x 有路径”
误写成双向投影。编码辅助变量不要求唯一，也不准反过来改变原始变量身份。

11.2 V/B 输入与 guard 合同吻合。
§1 允许 V/B 分别采用各自 X，或者预先统一全同址 X 再用常量排除不匹配值；
两者都要求一次编译保持同一编号。B 中调用/分支位置已是固定输入，自己的
索引由 F1 认证后才将 peer guard 逐读化；没有允许任意多读 guard 被独立
删源。val_x 可只在恰一 RF 的赋值上解释，形式化总公式时可写成
“恰一 RF ∧ 每条被选来源的取值/guard 条件”，故非法 x 无定义歧义。
§1/§5 正确区分完整索引值锁定控制来源与仅分支下的跨代来源见证。

11.3 固定 pi 不要求 SB 引入顺序。
§2 在任何 J/alpha 之前固定语法编号、失败串及袋细化，ghost 只补实际来源
等完成相关见证。§3 列的是 B1–B5/P1–P4 所需条件；没有把非 SB 引入布局
再拿去套依赖 SB 排列的 U 边界证明。失败链先建立固定骨架袋，再细化为
完整真实事件组，属于本审查第 10 节允许的一般计划。计划不由 SAT 见证选择。

11.4 给定证书与协议构造器没有混同。
§3 只在有效证书前提下给后端精确性；§4 另负担输入合同匹配、协议规则
可靠性和显式预处理费用。Lambda 属于明示语法输入，OUTSIDE 不被解释为
UNSAT；额外接口覆盖证书也没有被声称能从任意共享地址程序自动构造。
§6 的 G 参数分离和执行图/候选图量词分离不推出更广算法下界，§7 保留
二元/原子、前沿/失败链、完整值/分支的不同前提，符合各支撑定理。

11.5 复杂度使用的规范化约定。
O(Kn) 组数来自本文稀疏简单候选图、每候选对常数个二元/固定边组、每事件
常数个一元测试及一个统一常量入口；不是允许无界冗余空组的任意输入序列。
旧后端可以采用该规范计划。RF 溢出立即拒绝，使接受中间状态的来源计数
只取 0/1，得到指数中的 +K；若选择暂存溢出状态，则应另计其更大状态域。
这些都是明确的构造选择，不需要求解或重新选择 H。

本节结论：主合同的逻辑强度未超过已有证明；FULL、原始文字查询及一般
公式投影三者已作正确区分。对显式预处理次数的核对另见下一节。

12. 对 CONSTRUCTION 的独立复杂度与量词审查
==========================================
本节对照具体 Build 各步骤核查，而不是仅接受“预处理多项式”的结论。

12.1 宏规则没有隐含语义求解。
BufferPass 先验证固定程序位置与唯一写者，再由 F1 确定自己的索引。两侧
F2 下界表先完整产生；对每个超出上界的实际候选，查找真实存在的反馈读，
列举其全部剩余候选及共同 SB 前序，再应用 R∀/R1。不存在从某个完成的
具体来源建立永久 H 的步骤。不存在所需中间写时，线程无缺失前缀与来源
下界使相应候选域为空，而不是补造中间事件。数据来源仍交给最终后端。

BarrierPass 的 Br-Lower 是有限白名单中的已证协议宏：读—reset—读控制
位置及真实写者必须先匹配，宏可靠性来自 B1/B2 的对任意完成归纳证明。
其核验可引用该既定规则及有限索引，不要求临时确认“任意模型中都成立”。
同样，任何未来新增协议不能仅靠声明一个宏名字获得可构造性；须先证明
规则可靠性并给可检查的语法前提。这属于固定证明核，不是语义蕴含 oracle。

Publication-noG 的追加 NetPass 也已复核：仍要求完整 P1/P2，按显式单写者
来源链前向最早/后向最晚扫描，而不是枚举 RA 完成；来源块锁定后再通过
共同前序和闭包生成 h=2d+1。其省去的是 G/短跨度步骤，不是完整观测前提。

12.2 八次位界的有限操作账本。
原始域至多 O(n²) 位；每个域元素最多删除一次，每个 H/L 关系对最多加入
一次。故饱和发生变化至多 O(n²) 轮。每轮矩阵闭包及 R1/R2/R∀ 扫描至多
O(n³) 个关系单元操作，得到 O(n⁵)。协议 Pass 对 O(n²) 个候选逐一列出
至多 n 个来源前提；即使朴素地在必要处重算闭包，也可由同阶多项式覆盖。
用 O(ell²) 覆盖数值比较、加减、取模与引用开销，饱和不超过 O(ell⁷)。
独立重放有限记录、计划检查和朴素输出留在 O(ell⁸) 内是保守而有效的。

这里 ell 包含全部显式事件、观测、角色/组件合同及原始注册表大小。证明只
枚举实际出现的事件/阶段，不循环到二进制表示的容量或模数数值；允许集合
也只取显式列表或明确的简单谓词。因此次数没有掩盖指数长度的隐式枚举。
原始 ID/标签的位长需计入输出，MAIN_CONTRACT 已另留 poly(log ell) 因子。

每个首次推导只记一个永久记录，R∀ 最多附 n 个来源和已有事实引用；域版本
可按删除日志回放。即使存 O(n²) 轮的 O(n²) 位矩阵快照及 O(n²) 层的显式
袋/组，仍在所述 O(ell⁶) 证书长度内。因而复核承诺没有要求重新求精确 H。
组件成本求和使用地址闭合的平坦分区；若允许递归表示，应先展平成对应叶
组件并检查布局，再使用 Σn_i≤n，不能把重复覆盖各层误记为这个不等式。

12.3 固定计划与后端费用接合。
Layout 由输入阶段、固定角色次序和固定拓扑排序打破平局；Buffer-chain
由已观测失败串、固定来源锚和窗口登记位置展开。全部选择发生在摘要状态
搜索之前。失败链右锚可先引入，但完整真实 SB 必须随后装入联合监视器；
虚拟处理位置/规划超边不变成语义边，故同一 FULL 证明继续适用。

预处理可先按 O(n²) 枚举候选与组；CERT 的规范二元图计划宽度为 K 后，
简单图路径袋界再给 O(Kn) 个候选对，每对仅常数个组，所以后端层数收紧为
O(Kn)。这两个上界对象相同，只是使用的已知条件不同，互不矛盾。尚未通过
结构证书时不能预先按 O(Kn) 省略生成/检查费用；正文已把它放入 T_pre。

12.4 最终审查结论。
本轮发现并显式闭合了一处接口前提：可靠 may-RF 本身不足以保证输入 guard
已被执行，须追加本稿第 2 节的精确观测/逐读 guard 过滤条件。Build 原本
已经执行此步骤，所以该修正只收紧给定证书定理的书面前提，不改变协议界。
MAIN_CONTRACT 和 CONSTRUCTION 共同给出两个层次：给定有效证书上的全部
赋值投影，以及受限显式协议合同上的统一多项式证书构造。通过结构检查不
代表 SAT；OUTSIDE 不是 UNSAT；不完备 H/D 不破坏 FULL，剩余非法选择由
全局 RA/CO 监视器拒绝。未发现需要以 SAT 求解、逐完成布局或隐含额外观测
填补的数学缺口。结论限于文中明确的协议和观测合同；它没有完成新前端
工程适配、任意共享地址组合或任意布尔 guard 的自动编译。
