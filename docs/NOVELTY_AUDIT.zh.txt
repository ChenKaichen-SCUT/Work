结论
====
研究问题重要；当前已有一个受限语义片段上的证明稿、实际 TSO 执行子类和原型。
但是，不能据此确认已经形成足够强的顶会理论贡献。泛化求解、自动生成一致性
检查器、有界历史操作化、自动机支持传播都有直接先例。最可能有价值的增量是：
从关系结构可检查地推出闭包稳定的有限历史接口，精确保留部分 rf/co 赋值的所有
合法补全，并据此获得受结构参数约束的完备传播。当前只对一个较窄片段和协议
给出这条链条，尚未证明它相对已有框架的严格新增覆盖范围。

因此现阶段应优先推进理论：扩大关系片段、证明有效识别与闭包保持、给出有实质
差异的模型实例及边界。降低已有实现的状态生成成本暂列后续算法工作。
这不是文献穷尽性证明，也不是审稿或录用预测。“未找到相同定理”不等于首创。

1. 当前结果到底是什么
====================
依据 docs/proof_audit.txt、docs/optimization_proofs.txt 和 docs/METHOD.md：

输入：固定事件、地址、值、RF 候选与块分解；每地址 co 是严格全序；rf 恰好
给每个读选择一个来源；fr = inverse(rf);co。无环公理形如：
  P_j union (rf intersect theta_j) union optional co union optional fr。
theta_j 为静态端点过滤。跨块 co 必须已经有固定证书保证向前。

证明稿中的机制：保留固定跨界端点、仍可作为来源的写、来源入口端口、地址出口
端口；先闭包并检测内部冲突，再投影。方向化版本只保留未来入口到未来出口的
可达性。相同摘要共享后续状态，边标签保留每个原始变量的局部取值。

保证：对被接受的固定输入，路径语言精确表示合法 rf/co 补全；对任意原始变量
部分赋值，支持传播检出无解或全部必然原始文字。不保证对任意辅助变量决策的
传播完备性，也不保证与任意外部程序约束合取后仍由传播决定全部后果。

实际实例：普通读写与 MFENCE 的 alternating-flag TSO 成功分支执行族，固定
线程数、地址数和每轮负载，轮数任意有限；每地址写数随轮数增长。并非任意 TSO
程序、一般自旋循环、动态地址、RMW 或无限执行验证定理。

重要区别：
  - 不限制写数，是一个输入族上的界；每个被编译输入仍然有限。
  - 有界活动摘要，不是整个工具占用常数内存；历史变量标签和各层状态仍保存。
  - 现有编译器避免完整历史枚举，但会枚举局部选择和可达接口状态。
  - 多项式查询不能掩盖指数预处理；复杂度必须包括识别、编译、标签及解释。
  - 有效性证明与原创性是两项不同义务；实验一致性不能替代其中任何一项。

3. 创新性逐项裁决
================
主张                                      当前判断
----------------------------------------  -----------------------------------
模型公理输入 -> 自动求解/检查               已有直接工作；不可作为首创
无界写历史 -> 有界活动摘要                 一般思想已有；具体关系条件或可新增
相同未来行为的状态可合并                   标准语言等价思想；不是新主定理
有界接口 -> 动态规划                       通用结构方法；需具体有效构造

关系语法 -> 闭包稳定证书 -> 完备传播界      有价值的目标；一般版本尚未证明
一个真实 TSO 子类、任意有限轮数实例化       有意义的证明支撑；覆盖面仍偏窄
一般弱内存模型完整完备传播                 未证明，不应声称
普遍优于成熟工具                           实验未支持，也非理论保证

对现有工作最尖锐且合理的审稿问题会是：
“这是否只是把标准分隔集可达性摘要、自动机最小化与域一致性编码，套在一个
预先规定轮次屏障的 TSO 协议上？”
当前材料还不能充分排除这一评价。需要一个不能由上述标准组件立即推出的
关系结构定理，以及非人为特制的、具有不同交互机制的实例族。

4. 为什么值得继续，而不是立刻放弃
================================
完整检查一个已选执行图、寻找一个合法补全、对全部部分赋值求全部支持，属于
不同任务。固定 rf 的高效检查不解决任意 rf 候选域上的全部推论；但一个能处理
任意部分赋值的完整判定器，也可通过查询 T ∧ alpha ∧ ¬l 得到每个必然文字。
因此不能说“基线无法得到我们的结论”，应比较能否以统一有界编译和纯传播得到。

若只要求有限实例存在一个完备规则集，枚举全部不满足赋值、全部素蕴含子句或
全部模型就能获得指数构造。非平凡研究内容在于：适用类可识别、构造有效、成本
受结构约束、无需完整补全搜索，并且对回溯后的任意原始假设仍然精确。

L6 也给出推广的硬边界：除非 P=NP，不能对它证明 NP 难的整个输入类同时保证
多项式识别/编译和多项式完备冲突传播，否则在空赋值上就能多项式决定一致性。
因此新增结构参数必须能排除困难实例，不能仅换一个名字重复线程/地址/值的界。

我们已有的 fr 审计暴露了真实难点：旧写不再能充当 RF 来源，也可能作为未来
fr 的目标参与冲突。遗忘依据必须是未来可能影响，而不能只是事件年龄或已读性。
这提供了研究切入点，但这个例子本身不是足够的理论贡献。

5. 下一阶段的主线与停止条件
==========================
主线：关系公理下可有效识别的精确历史遗忘，与由此导出的完备传播综合。
目标合同和证明义务详见 THEORY_AGENDA.zh.txt。

优先级：
1. 为关系组合、受限交及闭包给出可组合的接口义务；先说明何时不成立。
2. 放松“所有跨块 co 已固定向前”，研究由稀疏一致性见证或有限观察类型取代它。
3. 证明关系/实例证书的检查成本、更新闭包保持、候选和原始标签的完整保存。
4. 在 TSO 之外完成一个交互机制不同的 RA/RC11 受限实例；不用换模型名充数。
5. 给出同一表示下的范围分离、摘要必要性或不可能性结果。
6. 上述完成后，再研究直接生成商状态、惰性构造与可撤销增量维护。

进入主要求解器开发前的研究门槛：
  (a) 主定理不以“存在一个恰好正确的有限摘要”作为全部实质前提；
  (b) 有一个从关系语法及可检查实例证书导出摘要的有效过程；
  (c) 至少一个实例超出现有成功轮次协议的交互结构；
  (d) 对 L2/L4/L5 的差别落在定理假设/结论，而不只是术语；
  (e) 完整标明识别、预处理、查询、解释成本，以及失败时的 UNKNOWN 边界。

若只能得到“假设有限未来等价类，则可以构造自动机”，应降低理论首创主张；
它可以作为论文基础，但不能代替弱内存特有的识别和闭包定理。
若无法找到有意义的新增结构类，应考虑转向更清晰的算法贡献，或调整研究问题；
不能继续堆叠通用引理来制造理论厚度。
