1. 输入、原始语义与两种观测合同
===============================
记 I=(E,sb,loc,kind,valW,O,Lambda)，n=|E|。E 是全部固定事件，写值与地址固定，
每地址有最小初始化；全 release/acquire、无 RMW/fence/NA/动态事件激活。
Lambda 是随输入提供的角色、地址归属、控制位置及组件接口合同，只描述程序
语法。验证 Lambda 不允许猜测 RF/CO，不要求自动从任意事件集发现协议。
今后写“由 I 决定”包括这个明确的可检查输入合同；不是隐去额外输入的简写。

Lambda 必须与各线程无缺失有限前缀一致。失败尝试、已发生的分支和未结束的
末次调用全部保留。任意漏掉中间事件的日志或未展开的动态控制不在本定理内。
无法匹配协议语法/地址归属/布局条件时返回 OUTSIDE，而非宣称原始 RA 无解。

原始 RF 注册表在协议/guard 删除之前建立：每个符合原观测 O 的同址写读对
对应一个位；未记录值时含全部同址写。每个同址无序写对对应一个 CO 方向位。
初始化相关位、后续认证为常量的位都属于 X_I。固定编号后永不删除原始变量。

完整值模式 V：O 给每个读实际返回值（尤其全部控制索引读）。Phi_I^V(X_I)
要求恰一合法来源、全部固定值和已记录控制流、CO 严格总序/初始化最小，以及
  hb=(sb_adj∪rf∪init)^+，eco=(rf∪co∪rf^{-1};co)^+，irr(hb;eco?)。
固定值不符合已给程序/分支时，只有在这些约束已经属于 Phi_I^V 时才可报矛盾。

分支模式 B：O 给已观察的成功/失败分支，读值可仅属于允许集合 V(r)。令
val_x(r) 为赋值 x 所选择来源的写值，Phi_I^B 包含同一完整 RA 语义，以及
val_x(r)∈V(r) 和全部已发生 branch guard；未发生的末尾分支不补造。
缓冲中自己的索引读由 F1 认证，故这些 guard 可化为对单个 peer 返回值的
有限取值限制。不能把任意多读联合 guard 都无条件化为独立来源删减。
本稿只涵盖已证明可作上述化简的控制条件，任意新布尔程序条件另需编码/状态。

两模式的 X 可不同，分别对各自 X 和 Phi 陈述定理，不能混用见证。也可选用
统一的全同址 RF 注册表，再把观测值不匹配位固定为 false；两种约定等价，
但一次编译从头至尾只能使用同一约定。

循环缓冲的模数记 m=C+1，避免与事件数 n 混淆。F3 窗口含至多 m 个连续
整数，模 m 在窗口内单射。因此在 V 模式下每个控制读至多一个合法来源，
可满足时恰一个；非平凡 RF/CO 选择须由并发数据区域等提供。纯缓冲的完全
观测本身可能把全部选择确定，不宣称它仍有跨代控制歧义。
B 模式可保留多个满足 guard 的控制来源，FEEDBACK §7 的 W_1/W_3 见证
只属于这一模式。数据区域见证不需借用未记录的控制返回值。

2. 编译前固定的对象与可以随完成变化的对象
=========================================
统一证书 Gamma_I=(D,H,L,Pf,Owner)：D 是可靠 may-RF，H/L 是可靠 must-HB/CO，
Pf 是按已证规则生成的推导记录，Owner 给出各原始位唯一标签归属。
G_I 是由全部 D 候选、L 未定写对、Cov(L)、真实相邻 sb 和稀疏初始化生成的
候选并图。它包含互不相容选项，不是任何一条已选执行图。
pi_I 是完整组顺序、袋、引入/退休及端口计划。普通版本从固定线程兼容布局
产生；失败链版本采用固定骨架袋细化，pi_I 不必是保持 sb 的事件引入排列。

决定这些对象只用 I 和固定的处理约定：线程/事件按输入编号排序；闭包和饱和
按固定规则顺序；组合图的拓扑序用固定编号打破平局；失败串按语法位置编号。
它们全部先于完整赋值 J、临时假设 alpha 和摘要状态搜索确定。

源于 J 的 ghost gamma_J 可以记录某读真正选中了哪个发布代、未记录的返回值。
但调用编号、已完成操作数、失败链边界、地址角色和布局阶段由输入控制位置
决定，不能随 gamma_J 改变。协议的区间定理对任意 J 成立，才能删除区间外
候选；不能选定一个区间内来源再构造 Gamma_I。

定理 U（统一量词）。对协议构造器返回 CERTIFIED 的 I，有同一
Gamma_I,G_I,pi_I，使
  ∃(Gamma_I,G_I,pi_I) ∀J [Phi_I(J) ⇒ ∃gamma_J.
                    Annotated_I(J,gamma_J;Gamma_I,G_I,pi_I)]。
Phi_I 在 V/B 两种模式中分别取其定义。Annotated 表示满足来源域、H/L 下界、
协议注释和同一候选计划；不要求 ghost 唯一。

证明。先运行构造器：协议语法编号和阶段固定；各协议规则对每个合法 J 可靠；
据此作的删边/闭包/R∀ 都保持所有合法 J。候选图与计划从该固定证书一次生成。
最后对任意 J 按其 RF 身份填入 ghost 并引用各协议引理，得到所需注释。
因此存在量词位于 ∀J 之前，不是先取得 J 再找一个窄布局。证毕。

当永久证书为空域或自环已经证明 Phi_I 无解时，直接构造恒假制品，原始变量
表仍保留。不能以“无解下量词空真”充当协议非空性或参数分离的证据。

3. 第一层：给定证书的精确编译定理
=================================
先要求观测语义已经落实：固定值、允许值及已证明可化简的 branch guard，均
精确转为逐读来源允许限制并执行。保留的候选必须满足这些限制；排除的原始
位留作 false。缓冲自己的索引由 F1 固定，是 guard 化简的证明前提。
仅有“D 是可靠 may 超集”不够保证反向投影；不能保留违反 guard 的候选，
再假定只检查 RA 的后端会自动排除它。一般联合 guard 不属于本合同。

前提是有效的 Gamma_I 及满足以下条件的统一计划 pi_I：
  (i) 每个事件袋寿命连续；
  (ii) 每组全部替代项端点在同一处理袋，所有实际 sb/init 也被处理；
  (iii) 最后关联组后才退休，RF 计数在此时检查恰为 1；
  (iv) 原始变量恰由一个组/常量层赋值，所有候选都被覆盖；
  (v) RA/CO 监视器及计数联合建键，后续端口取全部尚未处理候选的并集。
这些分别对接 RELATIONAL_FORGETTING_THEOREMS 的 B1–B5，以及
FUTURE_PORT_THEOREMS §3、P1–P4；不是新发明的通用知识编译步骤。

若二元计划事件袋大小至多 K，令 S=2^(33K²+K)。则可以构造支持图及对应
支持编码 A_I(X_I,Y)，大小 O(|X_I|+KnS)，并且

  对全部 x∈{0,1}^{X_I}： Phi_I(x) ⇔ ∃y A_I(x,y)。       (FULL)

这里使用规范计划：每个候选端点对只设常数个实际组，每事件只设常数个局部
检查，常量标签统一登记，不重复插入空组。区间袋表示的简单候选图有 O(Kn)
条边，故组数也是 O(Kn)；任意冗余给定计划先作这种不改变选择语义的整理。
RF 计数一旦超过 1 立即拒绝，未退休的有效计数只有 0/1，因此只需 K 个位。

构造工作量为计划预处理加 O(|X_I|+KnS poly(K))。有效证书的可靠性不是由
一个语义蕴含 oracle 决定：这里或作为定理前提，或由第二层受限协议核提供。
若只有给定证书的前提，就只承诺这一层，不能偷称任意 RA 输入的构造定理。

证明 FULL，分四步。
第一，协议和可靠过滤确保合法 x 的每个真实来源仍在 D，所有固定文字与 x
相符；反方向，剩余候选仅是必要条件，最终完整 RA 检查仍不可省去。

第二，对 L 未比较的每对写选一个原始方向，令 g=Cov(L)∪所选方向。
g 无环时 g^+ 是扩张 L 的严格总序：已比较对由 Cov(L) 路径覆盖，未比较对
由自己的方向边覆盖。任一扩张 L 的 CO 也恰给出这样的选择。每个 CO 位要么
是常量，要么在对应二元组中被赋值，不存在未注册、仅凭事后可达性猜出的位。

第三，合法 x 沿自己的选择进入各组，真实 RF 与逆 RF 成对安装，完整 RA
禁止游走与 CO 环检测均不拒绝。反之，接受路径的恰一 RF 计数及 g^+ 给出
全局 RF/CO；所有监视器对同一已选历史检查，故满足 Phi_I。P3 的后缀等价
只合并联合状态，保留入路径标签，所以拼接不会制造仅局部分别可行的伪模型。
事件退休后，其原始文字仍在路径标签上，X 不随活跃袋缩小。

第四，用已有支持 CNF（RELATIONAL_FORGETTING_THEOREMS E1/E2）表示该
接受路径集合。任一合法全赋值可取相应图/编码内部状态 y；没有接受路径的
全赋值不能扩展成编码模型。因此得到 FULL，而非只证明逐文字无条件支持。
已被排除的 RF 位以 false 常量标签/单位约束出现；与它矛盾的 x 无扩展。证毕。

4. 第二层：协议构造定理与费用
=============================
算法和保守多项式界详见 CAUSAL_FRONTIER_CONSTRUCTION。构造器依次完成
输入合同检查、注册原始位、协议区间规则、可靠关系饱和、稀疏候选生成、
固定布局/袋细化与逐项覆盖检查。没有枚举 RF/CO 完成，也不计算全部共同
语义后果。输出的 H/L 可以不完备，但足以得到下列界。

支持的协议合同及参数：
  旧发布网络去 G 版本：theta=(p,a,b,d)，K≤(2d+1)b+ap+p+a+1；
  缓冲有限尝试版本：theta=(a,C,B,q)，b=2(B+3+2q)，K≤(C+2)b+3a+3；
  缓冲纯失败链版本：theta=(a,C,B)，K≤2(C+2)(B+3)+3a+4；
  星形读写屏障：theta=(p,a,B)，K≤2[pB+5(p−1)]+ap+p+a+1；
  平坦地址闭合且布局兼容组合：theta 包含各组件前沿参数及全局 p,a、组件数，
      K≤Σ_i c_i+ap+p+a+1。
组合求和只用已证 c_i，不能把缓冲无限失败链的袋宽 K_i 代入。额外接口须有
完整地址归属或另行给出的有效覆盖证明；这里不自动构造任意共享地址接口。
本轮构造器接受平坦事件分区，不接受递归组件树；一般结构组合命题另按其
证书前提适用，不据此扩大本轮端到端构造算法的输入范围。

令 L_in 为事件、值、显式观测、协议合同等的总二进制输入长度，ell=L_in+|X_I|+1。
使用 CONSTRUCTION 的朴素构造，有明确的保守位复杂度
  T_pre=O(ell^8)，证书与计划编码总长度 O(ell^6) bits。
关系饱和只有 O(n²) 次原子增删，每轮闭包和规则全扫描 O(n³) 个关系单元操作；
较松八次位界还包含取值/guard 算术、推导记录核验、候选生成、组/袋/端口计划。
它不遍历不存在的代号或全部模数取值，也不枚举合法执行。
协议构造器在此时间内返回 CERTIFIED、PROVED_UNSAT 或 OUTSIDE；布局不兼容
不属于 UNSAT。端到端关系单元/索引操作成本为
  T_pre + O(|X_I|+Kn·2^(33K²+K) poly(K))。
若统一换算为位操作，还需计入编号/标签等的 poly(log ell) 因子，不把任意长
机器整数当作常数成本。上述次数是易验证的保守上界，不是实现效率预测。
在受支持协议合同中 K≤g(theta)，因而该式为 f(theta)·ell^{O(1)}。
这不是固定 p,a 即可处理任意 RA 的结论，也不承诺求出最优布局或最强 H。

5. 查询、撤销与观测模式的两个完整入口
=====================================
由 FULL，对 alpha 为 X_I 原始文字合取、l 为原始文字，有
  SAT(Phi_I∧alpha∧l) ⇔ SAT(A_I∧alpha∧l)。
V 模式使用 Phi_I^V、X_I^V、A_I^V，B 模式使用 Phi_I^B、X_I^B、A_I^B；
两套各自满足 FULL，后者包括 guard。gamma 只要求存在，不要求唯一。

支持扫描只保留与 alpha 不矛盾的标签路径。一轮前后向扫描得到无解或所有
原始支持/必然文字，成本线性于显式图、标签、假设及输出；支持 CNF 的纯 UP
合同只针对原始文字假设。更换/撤销 alpha 不重算永久证书，也不重新选择布局。

FULL 在逻辑上也可与任意只含 X 的公式 B(X) 合取而保留存在投影，但不能因此
宣称任意 B 都能用一次线性扫描处理，或任意辅助变量决策后仍传播完备。
特别是能分别支持 l1 与 l2，不保证 l1∧l2 有支持；完整路径投影保留这种相关性。

6. 应写准确的两个分离结论
=========================
G 参数分离：STRUCTURE CF4 的合法无限族满足
  sup_n K(I_n)<∞，而最小写覆盖 G_min(I_n)→∞，
且首写到后期读的长 RF、首末写的长 CO 覆盖边有真实支持。
若旧合同要求统一固定 G_0，该族不能被任何固定 G_0 统一覆盖；若旧定理允许
每个有限输入选择任意 G，则每个 I_n 仍可能适用旧定理，只是旧参数失去统一界。
因此主要结论是消除接口界对 G 的依赖，不是所有有限输入可适用性的严格包含。

执行图/候选图的量词分离：无反馈单址族中，已选 RF 图可各自具有常数宽度，
而全部合法来源候选取并含 K_(n,n)，统一候选接口无界。完整证明及“所有完成”
与“仅列出的几个完成”的区别见 QUANTIFIER_AUDIT。它否定从逐执行窄图直接
推出统一候选窄图的逻辑推论，不是对 MSO、SAT/BDD 或全部其他表示的下界。

7. 正文范围与完成标准
=====================
主定理用二元 RF/CO 分组。原子 RF 分组须额外最大域 d 或超边袋证书；不能
把其语义保真误当成宽度保持。前沿求和与失败链袋展开是不同定理入口。
范围表应同时列：V/B 观测；二元/原子；前沿/展开；地址与布局组合条件。
原始 |X| 可能为 Θ(n²)，不能从 K 有界推出制品总内存常数或线性于 n。

本轮收束标准就是 U、两层构造合同、FULL 和上述范围精确化。任意交错的
无限失败链组合、更强的统一指数模型族，属于后续可选增强，不为本轮新增
必备条件，也不以未完成这些更强结论为由拖延理论正文重组。
现有 compile_frontier() 内部调用旧 recognize() 并按 order 排序组，尚无导入
本稿外部协议证书或任意失败链组计划的接口。理论复用 P1–P4，不等于现成 API
已完成适配。尚无新前端实现、实验、PDF 或机械化认证；这里只结束本轮理论合同整理。
