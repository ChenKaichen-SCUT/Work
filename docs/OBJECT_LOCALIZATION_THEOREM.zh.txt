对象有向无环遍历下的 RA 完整支持分解与参数界
2026-10-19；证明稿，未由证明助手或外部研究者认证

0. 结论与贡献边界

本稿新增一条与发布网络不同的充分条件。它不重新使用完整交替读序列，也不
假定来源新鲜度、共同 HB 分隔或一个已经很小的候选图。给定地址的对象归属和
线程的对象访问顺序，检查一个对象图是 DAG，便可推出：

  合法原始 RF/CO 赋值集合 = 各对象局部合法赋值集合的笛卡尔积。

因此，全部支持可逐对象编译再串接，局部事件接口 k <= c+s；c 为单对象最多
非初始化事件数，s 为单对象最多地址数。Moir–Anderson 一次性 splitter 网格
每线程每对象至多四个事件、每对象两个寄存器，故 k <= 4p+2。

这比“存在小图宽度，然后应用知识编译”多证明了一个语义消去结论：在下述
条件下，删掉跨对象的程序序边不改变任何原始 RF/CO 赋值的可行性。删边一般
不可靠；第 7 节给出明确反例。界的参数不含网格对象总数或独立批次数。

这不是 P2 的局部语法改写，也不是所有旧发布网络都满足的新假设。两个充分
条件取并集，扩展工具适用类：旧定理处理反复复用少数地址的同步网络，新定理
处理一次性对象的无环路由。新条件不覆盖任意反复使用同一网格的长生命周期协议。
笛卡尔积、DAG 检查、SCC/图分解和知识编译本身都是已有概念；这里给出的是
本项目 RA 模型中的具体保持定理和来源明确的实例化，不宣称首次发现一般组合性。

1. 语义和前提

语义与主稿一致：固定有限事件、固定地址和写值；release 写、acquire 读；无
RMW/fence/SC/非原子访问/动态事件激活。每地址一个初始化写，并且在该地址
CO 中最小。读观测可以是固定值，也可以未记录值（匹配全部同址写）。

  hb = (sb_adj ∪ rf ∪ init)+
  fr = rf^-1 ; co
  eco = (rf ∪ co ∪ fr)+
  irreflexive(hb ; eco?)

其中 init 是各初始化写到全部非初始化事件的边。RF 是每读恰选一个合法来源，
CO 是每地址严格总序。变量 X 包含全部原始 RF 位及全部同址写对的 CO 方向位，
识别后常量也保留。未记录读值不等于允许任意分支：下一对象的地址已经确定时，
必须有足够的分支观测支持；本次抽取只在终止前缀的最后一次读允许未记录值。

对象划分 π：每个地址属于且只属于一个对象；事件（包括初始化）继承其地址的
对象。由全部相邻 sb 边 e→f 建图 T：π(e)≠π(f) 时加入 π(e)→π(f)。检查：

  O1 地址归属完整，且同一地址不能拆分给不同对象；
  O2 T 是 DAG；
  O3 每对象非初始化事件数 <= c，地址数 <= s。

O1–O3 均从固定输入直接检查，不使用某个选定的 RF、CO 或可满足性搜索。
O2 使同线程在一个对象上的事件连续；否则离开再返回就产生对象图上的环。
实际路由图可以比 T 大：若路由图无环且程序只沿其有向边移动，则 T 必无环。

将输入限制到对象 o，保留其全部事件、全部同址候选、局部初始化、每条线程在
该对象的程序序，得到 I_o。局部 CO/RF 选择无需从全局执行中预先投影出来。

2. 引理：全局初始化 HB 边可以消去

对于任何满足来源类型和 CO 总序/初始化最小约束的赋值，令
  hb0 = (sb_adj ∪ rf)+。
则 irreflexive(hb;eco?) 当且仅当 irreflexive(hb0;eco?)。

证明。初始化写不在任何线程中，RF 的终点必须是读，init 只指向非初始化事件，
因此初始化写没有入 HB 基边。向 hb0 加 init 后增加的可达对只能以初始化写为
起点。另一方面，初始化写没有入 RF 边、没有入 CO 边；fr(r,i) 要求读来源
在 CO 中先于初始化 i，也不可能。因此没有任何非空 ECO 路径进入初始化写。
一个新增 hb 对 (i,e) 不可能由 ECO 回到 i，e 也不是 i。故它不可能新增禁止环。
原 hb0 是 hb 子集，反方向直接成立。证毕。

注意：这里只消去 HB 基边，不删除初始化事件，不删除其 RF 选项，也不取消
初始化最小的 CO 约束。RARegistry 中这些原始位仍然存在且可查询。识别核继续
使用全局初始化关系产生可靠事实，不影响此等价性。

3. 引理：HB 不能离开对象再返回

对 T 取拓扑序 τ。RF 两端同址，故 τ 相等；对象内 sb 的 τ 相等；跨对象 sb
严格增加 τ。因而任意 hb0 路径的对象序号不降。若路径两端都在 o，路径不能
经过其他对象，否则必须严格增加后再下降。因此

  hb0 限制到 E_o×E_o = (sb_adj|o ∪ rf|o)+。

跨对象的 hb0 自环也不可能。RF、CO、FR 都同址，故 ECO 的每条路径更强地
停留在一个地址内。这个论证对所有候选 RF/CO 赋值同时成立。

4. 主定理：原始支持的精确对象分解

设 O1–O2 成立，F(I) 是 I 的全部合法原始赋值集合，X_o 是对象 o 的变量。
则 X 是两两不交的 X_o 的并，且

  F(I) = ×_o F(I_o)。                                      (1)

证明。
(a) 类型约束、每读单一来源和同址 CO 总序全部对象局部，故候选赋值先有一一
对应。此处保留原始身份，不合并同值写。
(b) 用引理 2 消去全局初始化 HB 边。任意违反 irreflexive(hb0) 的环只能位于
一个对象；任意违反 irreflexive(hb0;eco) 的环，其 ECO 段两端在同址，HB 段
因引理 3 也完全位于该对象。所有全局禁止环均是某个局部禁止环。
(c) 反过来，每个局部禁止环也是全局禁止环。加回全局初始化边由引理 2 不
改变合法性。故一个组合赋值合法，当且仅当每个局部赋值合法，得到 (1)。证毕。

推论。对任意原始部分赋值 α，令 α_o=α∩Lit(X_o)。全局可满足当且仅当每个
F(I_o)|α_o 非空。全局可满足时，属于 X_o 的文字 l 有全局支持，当且仅当
它在该局部问题有支持：局部见证可与其余对象的任意见证组合。撤销和改写查询
不需要重建任何语义证书。任一对象无解则全局无解，不能仅报告其余局部的支持。

这不是任意外部公式的分解定理；额外跨对象约束需要另行处理。编译图本身仍
精确表示全体原始赋值，但本项目的完备传播范围仍限于原始文字部分赋值。

5. 参数界与构造

A. 直接逐对象编译。
每个 I_o 至多 c+s 个事件，即使保留所有原始 RF、所有未决 CO、Cov(L) 或
最终相邻写候选，也只有这些局部端点。原子 RF 组 (r,*D(r)) 的全部端点也
位于同一对象，无须旧阶段证明中的二倍跨度补偿。因此二元和原子组统一满足

  k <= c+s；splitter 中 c<=4p，s<=2，所以 k<=4p+2。         (2)

局部编译仍使用既有 RA 关系监控器。令 S=2^(33k²+k)，接原有状态计数可得
保守总表示大小 O(|X|+k² N S)。实际更精细地为各局部图大小之和，而非其笛卡尔
积：用空标签连接前一图的接受态与后一图的起点，再映射回全局原始变量编号。
每个接受路径恰给所有原始变量一次赋值。标准支持 CNF/图扫描保持完整支持。

此步骤的图串接、支持扫描和支持 CNF 是既有方法；新增的是允许做此分解的
语义证明及可检查条件。理论上可按对象构造索引，预处理计费为输入扫描和各
对象识别成本之和。当前 Python 数据结构仍有全局候选/变量扫描，未承诺实际
实现线性运行时间，也不把 p 可增长时指数状态常数隐藏掉。

B. 不做语义分解，直接布局全局候选图。
按 τ 逐对象排列事件，各对象内部先放局部初始化，再放线程局部事件。消去
init HB 后，一个已处理完对象中仍有未来关联的事件只能是跨对象 sb 的旧端。
每线程至多留下一个这样的旧端：两个旧端之间的线程程序段若未处理，会违反
τ 单调性。当前对象至多 c+s 个事件。因此

  k_global <= p+c+s <= 5p+2。                               (3)

这单独给出候选图的接口界，覆盖全部候选，而非一个已选执行。若依旧保留
global-init-to-thread-head 边，同时交错放置对象初始化，还能将各线程首事件
作为至多 p 个额外长期端点，得到 2p+c+s 的界。因此初始化消去不是唯一获得
常数接口的方法；不可宣传“旧初始化表示在任何布局上必然随对象数增长”。
旧的“所有初始化先放入并计入 a”的通用上界确实随总地址数增长，但只是该
布局/计费方式的限制。实测交错布局保留 global init 的基线也有有界接口。

6. 来源协议如何满足前提、如何打破旧 P2

来源为 Moir–Anderson 1995 的一次性 splitter 网格，不是其 Figure 5 的复用
版本。每个格点有 X、Y 两个真实协议寄存器；不同格点地址不同。right/down
均使 row+col 增一，stop 终止，因此对象图无环。每个线程最多访问某格点一次，
访问含 wx,ry 以及可选 wy,rx，故式 (2) 的参数自然成立。线程可能从未访问
大部分格点；没有任何“每线程必须观测所有轮次”的要求。固定 trace 的终止
前缀同样适用，只需保持已执行事件和已确定路由。

旧 P1 不成立：X/Y 均可多写者，Y 只有 false 初值和 true 发布，无独占交替
发布块。旧 P2 不成立：一次性对象没有完整 0,1,0,1 等待序列，也没有最后一次
观测约束来源块号。新证明甚至不需要固定读值，除非这些读值用于确定后续路由。
P3 中按对象计的有限密度自然成立，旧长期写覆盖问题在一个对象内部没有跨轮
复用意义；总初始化数随网格/批次增长，这次用局部 s 替代全局 a。

多来源不是靠版本值或额外竞争写构造：右行者读到 Y=true，来源可以是不同
左分支参与者各自的 wy。其 CO 也可以有多个合法方向。具体完整支持和缺陷
见 SPLITTER_PROVENANCE.zh.txt 及 results/splitter_20261019。

7. 必要性反例与适用边界

若去掉对象无环条件，按地址分解可不可靠：
  x=y=0；T0: R(x)=1; W(y)=1；T1: R(y)=1; W(x)=1。
将 x、y 各作一个对象，两个局部问题各自合法；合并则 RF 和 SB 构成 HB 环，
全局非法。对象图恰有 X→Y→X。测试同时核对局部可满足、全局不可满足及
证书拒绝；不是仅测试异常消息。可以先合并对象 SCC 再应用定理，但 SCC 很
大时参数也大，当前 API 不自动宣称小界。

本次推广不证明复用少数地址的 Peterson、长生命周期 splitter 或任意屏障满足
新界；这些程序可在对象图中产生回路或单对象事件数随轮数增长。反复实验的
batch 参数使用互不别名的新网格，这是一个显式工作负载，不冒称原论文的
长生命周期算法。参与者 p 增长时局部 CO 排列仍可能导致指数状态，7/9 线程
的资源失败必须保留。它支持另一种重要的应用结构，但不能独自消除所有实际
适用性或学术新颖性疑问。

8. 已有工作与新增工作的逐项区别

Moir–Anderson：给出原子寄存器上的协议和正确性/步数界；未给这里的全 RA
移植保证。本稿不重证或占有其 splitter 设计。
关系 may/must 分析（包括 Dat3M）：仍用于对象内部剪枝；本稿不增加新抽象域，
也不声称它们不能表达相同后果。分解证明不需要 R_∀ 或完整交替链过滤。
已有接口/知识编译步骤：小接口到关系监控状态、标签图、支持 CNF 的转换沿用。
本次新增的项目论证：初始化 HB 消去；对象 DAG 上禁止环的定位；全部原始
模型集合的双向乘积分解；原子组同样 k<=c+s；来源程序中的 c<=4p,s<=2。
已有一般组合性研究并不少：Compositional Verification of Compiler Optimisations
on Relaxed Memory (ESOP 2018, DOI 10.1007/978-3-319-89884-1_36) 等研究不同的
上下文/程序变换目标。本次检索不构成文献穷尽，不能由未搜到同名结论推出
“首次”。论文应以明确假设和严格相等式 (1) 陈述结果，进一步查重后再定位创新。
