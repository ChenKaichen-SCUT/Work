以协议因果关系替代 P2：集中式 sense-reversing 屏障的逻辑推广
2026-10-19；数学证明草稿，不是实验归纳结论，尚未接入现有求解器

0. 纠正研究主线

对象 DAG 分解是另一类充分条件，不能冒充对旧 P2 的放宽。本稿回到共享地址
反复复用：分析一个有原始规范的屏障，在同一 count/sense 上反复调用，保留
真实的 RMW 多来源和未决 CO。证明目标是从协议原子性、程序序和 coherence
推出来源局部性，而不是从实例跑通或轮数增长推测普遍结论。

需要明确增加的语义能力：acq_rel 的 fetch_sub(count,1)，以及其算术结果与
“是否最后到达”的分支。旧项目无 RMW、固定写值的前端不能直接表示它。
这是来源协议本身所需的扩展，不是为了凑多写者而增加操作。本文的正结论
是新语义下的证明稿；不能引用 splitter 的实验作为它的正确性或实现证据。

来源：Mellor-Crummey/Scott 的 Scalable Synchronization 作者伪代码页，
“A sense-reversing centralized (non-scalable) barrier”：
https://www.cs.rochester.edu/research/synchronization/pseudocode/ss.html
网页给出 count 初值 P、私有/共享 sense、原子减计数、最后者重置并发布、
其他线程等待。网页说明它与 Hensgen/Finkel/Manber 1988 等已有算法有关。
我们分析明确的 C11 内存序赋值：减计数 acq_rel，count 重置和 sense 发布
release，sense 轮询 acquire。不是宣称该网页原样给出了这些 C11 注解。
为简化符号，将网页的共享/私有初始 true 同时取反为 0；这只是布尔重命名。

1. 从原证明中抽出的真实义务

旧证明使用完整交替计数的地方只有起点：认证等待的全部来源位于前一发布块。
后续需要的实际上是来源集合所导出的必然因果关系，再用同址写覆盖排除远端
RF/CO 候选。因此替代机制必须先证明两个事实，而不能把它们当作新假设：
  (i) 某次调用不能凭过老的发布返回；
  (ii) 某次调用不能读取尚待其后续调用才能产生的未来发布。

RA 本身没有时效保证；删去完整序列并称“读应当足够新”不成立。新增机制
必须来自协议。本屏障中 (i) 来自前次释放的 HB 和 sense 翻转，(ii) 来自
RMW 的真实相邻性、参与者计数以及 HB 无环。这些义务均能在有限前缀中证明。

2. 精确语义与保留观测

p>=2 个固定参与者，各线程串行重复以下调用，无跳过、重入或额外 count 写：
  私有 bit 翻转；
  A=fetch_sub(count,1)；
  若返回 1：C=count:=p；S=sense:=bit；返回；
  否则：反复 acquire 读 sense，直到读到 bit 后返回。
初始化 count=p，sense=0，私有 bit=0。调用次数可以不同，输入可以在任意
线程处截断；只要求是程序执行前缀，RMW 是不可拆的操作。

把一个 RMW 表示为读 r 和写 w，r 在程序内先于 w；两者必须一同出现。
若 rf(u,r)，则 u 是 w 在 count 的 CO 中的直接前驱，且 value(w)=value(u)-1。
这是 RMW 原子性，不是把普通 load/store 当作原子减法。所有 count 写都是
release，RMW 读都是 acquire，所以这个直接前驱关系同时给 u hb r hb w。
重置写是普通 release 写，值 p。采用整数算术；下文证明正常合法前缀的计数
值始终在 0..p，因此选择能容纳 p 的机器整数也不发生下溢/回绕。

保留：线程内事件顺序、调用编号、last/non-last 分支、sense 读的成功/失败
判别、原始事件身份。可以不记录非最后者的精确 RMW 返回值；该值从所选
RMW 写序唯一恢复。全部原始 RMW-RF 位、普通 RF 位和同址 CO 位均可查询。
一个没有记录返回值的 RMW 不等于允许违反算术或分支，二者始终是语义约束。

旧前提对照：
  P1 失败：sense 的发布者由最后到达者决定，不是独占标志/同值重复块；
  P2 失败：每次调用观察当前释放，可有任意失败轮询，前缀不必包含未来调用；
  P3 的阶段密度可由下面的骨架计数替代，失败轮询数不必有统一上界；
  无 RMW 前提明确放宽；无 fence、固定地址仍成立；count/sense 仅两个地址。

3. 核心引理：计数区间中每线程至多一次到达

以下所有关系均针对任意一个满足 RA+RMW 语义的执行，而不是预先选一个
“正确”写序当假设。按 count 的实际 CO 将重置写编号 C1,C2,...，C0 为
count 的初始化。Si 为执行 Ci 的线程随后发布的 sense 写（前缀中可能尚未
出现），S0 为 sense 初始化。Ai,t 表示线程 t 的第 i 次减计数。

区间 i 指 Ci-1 与 Ci 之间的 RMW 写；若 Ci 不存在，则取最后一个开放区间。
证明如下联合归纳不变量：
  I1 每个已闭合区间 i 恰有 p 次到达，且是每个线程的第 i 次到达各一次；
     开放区间每线程至多一次到达，也都是其第 i 次调用。
  I2 区间 i 中每次到达前，Si-1 已存在并 HB 先于该次到达（i=1 用初始化）。
  I3 已闭合区间内的 count 写按 CO 同时组成 HB 链；各重置也依次 HB 有序。
  I4 已存在的先前释放依序 HB/CO 有序，Si 发布第 i 次调用的翻转位。

归纳步骤不能先假设屏障正确、再用它证明 I1。具体如下。

(a) 一个线程在区间 i 中首次到达时，调用编号必为 i：先前闭合区间已经各
含它的 1..i-1 次到达，CO 又由同线程 HB 保序。
若该线程是上轮最后者，Si-1 在自己的程序序中先于本次到达，I2 成立。
否则，它先通过上轮的成功等待。若该等待读 Sj，则 Cj hb Sj hb 等待 hb
本次 count 写。WW coherence 使 Cj 在本次到达之前，故 j<=i-1。
当 i>=3，归纳已给 Si-2 hb 上轮到达 hb 上轮等待；旧释放 S0..Si-2 的
CO 不晚于 Si-2，且上轮期望位与 Si-2 不同。WR coherence 和读值共同
排除它们。i=2 时初值与首次期望位不同，直接排除 S0。因此只能读 Si-1。
这证明 I2，也说明缺失 Si-1 的前缀不能凭空进入下一调用。

(b) 假设区间 i 出现同线程第二次到达，取第一个这样的反例。它之前的本轮
到达若返回 1，则程序序要求先执行自己的重置写再再次到达；WW coherence
会把这个重置放在本区间内部，矛盾。若不是最后者，则它必须先成功等待，
并读到与 Si-1 不同的位。由 (a)，Si-1 hb 该等待；先前所有释放都在
Si-1 或更早的 CO 位置，故不可能作为来源。来源只能是某个 Sj，j>=i。
但 Cj hb Sj hb 等待 hb 第二次到达，WW coherence 又要求 Cj 在第二次
到达之前。这与第二次到达在 Ci 之前、区间内部没有重置矛盾。
因此每线程至多一次到达。这不是完整交替序列的末端计数：只使用上次返回
和本次重复到达所必须满足的局部程序结构。

(c) 区间中没有重置，RMW 的来源必是 count 的直接 CO 前驱。起始值 p，
连续 m 次减法的返回值依次 p,p-1,...,p-m+1，写值 p-1,...,p-m。
由 (b)，m<=p。若 Ci 存在，它必须由一次返回 1 的到达产生。该到达不能
来自先前区间：每个先前区间唯一的返回 1 已对应自己的唯一重置。也不能
来自 Ci 之后，因为同线程 HB/WW 强制到达先于其重置。故它在当前区间。
要返回 1 必须 m>=p。因此 m=p，且 Ci 紧随最后一个 RMW 写，p 个到达
分别来自全部 p 个线程，I1 成立。不存在额外减到负数的到达。

(d) 相邻 RMW 的真实 RF 加 acq_rel 给出整个区间的 HB 链；最后一个到达
程序序先于 Ci，故 I3 成立。若下一闭合区间存在，执行 Ci 的线程也必须
贡献其下一次到达；Si 在该到达之前，后者又 HB 先于 Ci+1。因此
  Si hb Ai+1,last(i) hb Ci+1 hb Si+1
（最后一项若已存在），I4 随之保持。归纳完成。

4. 前缀稳定的来源定理

定理 A。线程 t 的第 i 次调用：成功的 sense 读只能来自 Si；失败的 sense
读只能来自 Si-1。结论适用于任意合法有限前缀，不要求每线程都有相同总轮数，
不要求未来某个“最后一次观测”存在。

证明。I2 给 Si-1 hb Ai,t hb 当前读，I4 给发布的 CO 顺序。WR coherence
排除比 Si-1 旧的来源。任意来源 Sj 若 j>i，则 Cj 已存在，所以区间 i+1
已闭合，必包含同一个线程的 Ai+1,t。I3 给 Ai+1,t hb Cj hb Sj。
另一方面，该次读发生在 Ai+1,t 之前，若读 Sj 则
  Sj rf 当前读 sb+ Ai+1,t hb Cj hb Sj，
形成 HB 环，矛盾。故来源只能在 {Si-1,Si} 中。成功/失败的读值分别等于
第 i 位/相反位，而二者值不同，分别只剩 Si/Si-1。证毕。

若当前读是开放前缀中的最后一个失败轮询，反证仍有效：假设未来 Sj 已在
输入中，其已完成计数区间迫使 Ai+1,t 也在输入中；这与该线程的前缀结构
或 HB 无环冲突。没有为证明补造未来事件。

与旧 P2 的实质区别：旧论证由 n 个严格递增来源块挤入 n 个位置得唯一性；
本证明由真实 RMW 前驱、局部重复到达矛盾和“读取未来释放会回到自己下一次
到达”的环排除未来来源。完整序列的长度 n 从未用于定理 A。

5. 候选跨度、原子分组和失败轮询的界

以线程调用编号为阶段。由 I1–I4/定理 A：
  count RMW 的可能来源：本阶段其他 RMW 写，或前阶段重置；
  count 的跨阶段 CO：全部已确定；未决 CO 只在同阶段到达之间；
  sense 的 CO：阶段顺序；成功 RF 同阶段，失败 RF 前阶段；
  必然 CO 的覆盖边、最终相邻写候选：最多跨一阶段；
  相邻 SB：最多跨一阶段。
这里固定 CO 的覆盖边也被计入，不只考察未决对。RMW 作为一个原子选择组
含“读、其配对写、所有候选来源写”，仍只涉及当前和前一个阶段，不能在
原子分组后偷偷扩大窗口。全部原始跨阶段 RF/CO 位仍保存为常量文字。

每阶段去除失败轮询后的骨架事件数至多
  b0 = 2p + (p-1) + 2 = 3p+1：
p 个 RMW 各有读写两事件；p-1 个成功读；一个 count 重置和一个 sense 写。
最后的开放阶段只会更少。两个初始化保留。

失败轮询不必假定至多 q 次，也不必语义删除其事件：定理 A 已使每个失败读
的 RF 恒为 Si-1。其余关联只有同线程的 SB 链。保留当前/前阶段的全部骨架
节点和 Si-1，在骨架端点之间逐个处理该轮询链，同时最多保留“前一个读、
当前读”两个额外节点。结束于前缀末尾的链没有未来端点，可以直接退休。
这给出一个明确候选组调度，其事件袋上界为

  k <= 2b0 + 2 + 2 = 6p+6。                              (A)

该界同时覆盖二元组与原子 RMW/RF 组，独立于轮数及失败轮询次数。长日志仍
有 N 个事件和 |X| 个原始位，界不意味着常数总内存或常数输出长度。只保留
候选生成边，而不物化稠密必然 HB/CO 的所有传递边。

现有监控器不能把 RMW 简单拆开后直接使用。接入时须强制 RF 来源为其配对
写的最终 CO 前驱；可在最终相邻写表示中，将选 rf(u,r) 与选 c(u,w) 原子
绑定，保留每写的出/入度和无环约束。两个选择具有同一局部组端点，故此项
必要的语义约束不破坏 (A)。这部分实现尚未完成，不计为现有实验支持。

6. 多来源和未决 CO 是协议本身的，不是额外竞争写

三线程 A,B,C 的一轮，保留 C 为最后到达者，A/B 非最后，但不记录二者的
精确计数返回值。两个合法次序：
  C0 → A → B → C → C1；C 读 B 的 RMW 写，CO(A,B)。
  C0 → B → A → C → C1；C 读 A 的 RMW 写，CO(B,A)。
按该顺序执行原子减法，最后者重置/发布，其他线程随后成功等待，即分别构造
出 SC 调度见证，当然也满足 RA。值由序位决定，分别返回 3,2,1；没有添加
同值竞争写，没有提前指定 A/B 写序。两条见证对任意轮数逐轮串接仍成立。

因此 C 的真实 RMW 来源有两个合法支持，而 A/B 的 CO 有两个合法方向；
它们还相关：假定 C 读 A 就强制 B 在 A 前，假定 C 读 B 就强制 A 在 B 前。
这给出使用完整支持的直接任务：仅保留 last/non-last 的屏障日志，在补录
某个 RMW 来源后，求所有仍可能的到达序、指出强制顺序及冲突补录。

7. 更强的纯协议表示推论（不依赖图宽度黑箱）

对记录了每轮最后者 ℓ_i 的 n 个完整调用轮次，定理 A/I1 说明原始 RF/CO
模型恰对应每轮“以 ℓ_i 结束”的参与者排列；每种排列按第 6 节的调度合法。
其他 RF/跨轮 CO 均为定理确定的常量。每轮有 (p-1)! 个模型，n 轮恰有
((p-1)!)^n 个模型；若另记录精确非最后返回值，则只保留与序位相符的排列。

一个直接支持 DAG 用状态 (U,last) 表示本轮已经到达的线程集合与最后一个
到达者；选择下一线程时，标注它的全部 RF 位，并标注它与尚未到达线程之间
的 CO 位。最后者只允许在其他线程都到达后加入。每个原始 CO 位在较早者
加入时恰标注一次，每个 RMW 读的全部 RF 位也恰标注一次。
每轮至多 O(p 2^p) 个状态、O(p² 2^p) 条边，每条边 O(p) 个原始文字。
故串接后的图/标签大小

  O(|X| + n p³ 2^p)。                                    (B)

来源域的跨轮假候选和已定比较也计入 |X|，没有从输出计费中消失。任意原始
部分赋值过滤路径后，前后向可达扫描给出精确支持；接标准支持 CNF 的步骤
仍是已有知识编译，而非新定理本身。此处的支持集合描述及计费为数学推论，
没有报告它已在现有求解器运行或优于成熟方法。

8. 扩展到屏障间工作时，哪些部分仍需假设

若每线程每轮屏障前有至多 B 个固定地址读写事件，count/sense 不被工作代码
访问，仍用上述协议调用，则任意阶段 i 的事件先于自己的下一次到达；后者
先于下一次释放，该释放先于任意线程阶段 i+2 的工作。因此得到 h=2 的
必然 HB 分隔。它由上述协议证明产生，不是作为未经证明的 C2 加入。
对工作地址仍需真实的 G 写覆盖；协议不会替应用保证每个地址被定期改写。
沿用既有候选删减证明，δ=2h+G=4+G，令 b0=(B+3)p+1，a 为初始化数，
再单独流式处理固定来源的失败轮询链，可得保守界
  k_binary <= (G+5)b0+a+2；
  k_atomic <= (2G+9)b0+a+2。
这部分把“新增协议因果论证”与“已有覆盖到接口的步骤”明确分开。

9. 还不能声称什么

屏障算法及其基本正确性是已有知识，不应包装成首次发现。本稿新增的是本
项目语义中前缀稳定的来源/CO 支持结构、原始身份保持的表示推论和参数界；
其文献优先权仍需检索与外部审查。式 (A)/(B) 的证明不依赖任何实验统计。
该路线确实要求 RMW 及返回值/分支约束，当前代码未实现这些语义，所以不
能宣称“已通过现有测试”。在独立审查前，它是明确可检查的证明稿，不能
直接替换已审阅的主定理。它也不推广到可退出/动态注册/不守协议的参与者、
可溢出且绕过约定的任意计数代码、或任意弱内存程序。
