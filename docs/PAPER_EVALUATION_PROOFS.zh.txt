本轮实验适配器的语义义务与证明
2026-10-15

这些是为了使实验任务可比较的正确性引理，不作为新的主要理论贡献。
主定理及其适用条件仍见 RELATIONAL_FORGETTING_THEOREMS.zh.txt、
RELATIONAL_RECOGNITION.zh.txt 与 CONSTRUCTION_ALGORITHMS.zh.txt。

1. 未观察的读值和性质下推

假定事件集合、线程顺序、地址和所有写值固定，读值不影响事件激活、写值、
地址或控制流。将某读 r 的值记为未观察，只允许其 RF 来源取任一同地址写。
一个 RF/CO 赋值唯一确定 r 的值为其唯一 RF 来源的写值。因而，在该接口上
扩展未观察读与枚举所有可能读值完全等价；这没有扩展到数据依赖程序。

对性质 P = AND_r(value(r)=v_r)，令 C_r 是值等于 v_r 的同地址写集合。
RF 的恰一约束给出 value(r)=v_r 当且仅当 OR_{w in C_r} rf(w,r)。因此，
在完整候选域上加入这些析取子句，与从每个被观察读的候选域中删除其他写，
在剩余 RF/CO 上的投影一致。两种方式的原始变量集合不同，不能直接比较
文字计数；本轮相同布尔后端实验始终使用前一种方式和相同变量编号。
多个读值条件相互矛盾时，性质为假；不能依次覆盖条件而丢掉矛盾。

2. 初始化星形边的稀疏化

令 I 是初始化写集合，sb 含各线程相邻事件边。旧初始化边是每个 i in I
指向每个非初始化事件；新初始化边仅从每个 i 指向每个非空线程的首事件。
新边是旧边子集；每条被删边 (i,e) 又有 i->线程首事件->sb*->e 的替代路径。
故对任何 RF 选择，两个图的传递闭包完全相同。初始化 CO 首位约束保持。
这里替换的是 HB 的生成关系，不是分别近似闭包后再组合，故共同见证保留。

3. 独立通用 RA SAT 编码的原始投影

范围是全 release 写、全 acquire 读的固定事件模型，无 RMW、fence、SC、
非原子访问。HB=(sb union rf union init)^+。每个读恰有一个来源，每地址
CO 为初始化最小的严格全序。将四类 coherence 条件展开为：
WW: H(w,w') => co(w,w');
WR: H(w,r) and rf(v,r) => (w=v or co(w,v));
RW: H(r,w) and rf(v,r) => co(v,w);
RR: H(r,r') and rf(w,r) and rf(w',r') => (w=w' or co(w,w')).
并要求 H 无环。以上是本实现独立密集 RA 判定器使用的四类条件。

SAT 辅助 H 只要求包含生成边、传递且非自反，没有强制 H 是最小闭包。
若真实 RA 赋值合法，取 H=HB 即得 SAT 扩展。反之，任何 SAT 的 H 都包含
HB；无环及四个蕴含对减少 H 边均封闭，因此 HB 同样满足它们。于是 SAT
在原始 RF/CO 上的投影恰是合法执行，不需要对 H 作精确闭包编码。
这种存在扩展只用于一致性与原始文字支持；不声称辅助 H 文字有真实语义。

4. 两种通用 BDD 基线

CNF-BDD 构造完整 CNF 的 Boolean 函数，再存在量化全部 H 辅助变量，由
第 3 条得精确 RF/CO 函数。Relational-BDD 直接以原始 RF/CO 为 BDD 变量，
用 Boolean-semiring Floyd-Warshall 计算每对事件之间存在路径的函数，
再合取四类 coherence、无环、RF 恰一及 CO 全序条件。每步使用同一原始
赋值下的合取/析取，因而保留路径共同见证及选择相关性。没有使用本方法
的历史摘要构造；它是更强的通用符号关系基线，避免先引入 H 再消去的成本。

对任一条件化后非假 BDD，从根访问所有可达非假后继。变量 x 的低/高边
若通向非假函数，即存在相应 x 值的满足延续。路径跳过 x 时，两种值均有
支持。把所有可达路径的这些信息取并，即得到每个变量的精确两值支持；
只有一个值有支持则它被强制。补边必须传到后继的符号，不能忽略。
实现用访问集合及跳层区间差分，成本 O(可达 DAG 大小 + 声明变量数)，
不通过逐变量 SAT 搜索弱化 BDD 基线。条件化本身的成本也计入查询时间。

5. C 输出程序的观察投影

生成程序只含固定 worker 线程、常量 release 写、acquire 读，以及主线程
初始化、创建、join、断言。每个观察结果槽只有对应 worker 写，主线程在
join 后读；这些额外地址不被 worker 再读，不连接不同 worker 的事件。
主线程的 join/观察后缀没有返回 worker 的同步边。因此删除这些辅助事件
保持原 worker 关系；反向可将任一原执行扩展为 worker 结果写及 join 后读。
结果槽只有一位 writer 且读位于其 join 之后，因此断言观察到对应读值。
断言写为 assert(!P)，故 native 工具的 assertion violation/FAIL 对应
P 可达，而 PASS/no errors 对应 P 不可达。
这只是该固定直线类的翻译，不是我们的任意 C11 前端。

6. Poct 公共子类适配

只对经过 pure producer/reader 单地址证书的实例运行 Poct。其 RA/SC 原始
投影相等已经由 CONSTRUCTION_ALGORITHMS.zh.txt 的线性化证明建立。
每个事件 guard 为真；每个 RF 候选绑定独立 Boolean，加入恰一约束；每对
写的两个 WS 方向互补；po 包含 sb 和初始化前置边。加入观察性质的 RF
析取子句。故适配器仅换语法，Poct 的 SC 执行恰对应公共子类的 RA 执行。
Poct 不是 general-RA 基线，原始 Zord 也不冒用 Poct 的名称或结果。
直接 SMT 输入不包含外部 C 前端耗时，结果必须分栏呈现，不宣称端到端同成本。

7. 实验的证明力边界

投影检查、随机部分赋值和独立工具结果一致可发现实现错误，但不是完备性
定理的证明。有限实例无不一致也不意味着任意输入正确。普通 SAT 通过搜索
能够得到同样完整的答案；我们与其比较的是获得全部原始支持的成本，不是
宣称其他完整求解器不能做到。普通 CNF 的 UP 强度不足只说明传播机制差异。
把支持 CNF 与任意外部性质合取后，全局传播完备性不随之成立。

8. 带 RF 歧义的非 SC 压力族

repeated_iriw(n) 有两个地址 x,y，分别一个纯写线程向各自地址写 n 次 1；
另有两个读线程依次观察 (x=1,y=0) 和 (y=1,x=0)。初始化为 0。
地址内 CO 由单写线程顺序唯一确定。每个读到 1 的来源可以是该地址任意
一个写，共 n^2 个原始投影。没有读后写或跨地址写同步，所有这些投影满足
HB 无环及四类 coherence，故 RA 可达，且读来源歧义随每地址总写数增长。
若存在 SC 线性化，设两次读到 1 的来源分别为 wx,wy；读到 0 必须在另一
地址第一个写之前，故 wx < rx1 < ry0 < wy <= ry1 < rx0 < wx，矛盾。
因此整个族都确实依赖弱语义，不只是增加了程序规模的 SC 可线性化实例。
它不声称拥有有界的当前候选边前沿；测得宽度和失败配置均需报告。

9. 构造诊断后的安全剪枝（独立版本）

对 read 的 RF 入度和非初始化 write 的最终 c 入度，合法完成均要求等于 1。
设 d(v,f) 是所有可能增加该度计数的候选组中最后处理的组。组序与候选集合
在构造前固定；已经处理的组不能在后缀中重新选择，后缀也不会新增候选组。
因此，处理 d(v,f) 后计数仍为 0 的前缀没有合法延续，立即删除它是可靠的。
计数大于 1 原算法已经拒绝，计数等于 1 则保留。该规则只是把原本在事件
遗忘时执行的必要检查提前，不增加、不修改任何合法完整路径及其原始标签。
故前后向支持集合、支持 CNF 的原始投影及传播完备性保持。

这是减少无效中间状态的算法剪枝，不是更改内存模型或缩小查询接口。它不
保证能消除联合关系矩阵的状态爆炸；本轮作为 post-diagnosis 的 pruning
活动独立记录，未改动正在运行的冻结主实验版本，失败也必须报告。

10. 直接 CO 生成关系：避免另外猜测最终相邻写见证

原 F 同时选择原始 CO 比较 Q 及最终相邻写关系 c，并由 irr(Q;c+) 约束二者
一致。即使每个完整 CO 的最终相邻关系唯一，中间阶段仍会生成大量无法完成
的 Q/c 组合。下面的替代构造适用于整个当前固定事件 RA 合同，而不要求纯线程。

令 L 为永久认证得到的同址必然 CO 严格偏序，cover(L) 为其传递约简。
对每个未被 L 决定的原始 CO 比较，按当前选择将对应方向加入 g；再加入
cover(L)。不再猜测相邻关系，不再维护写的相邻入/出度。保留所有原始 CO
标签和 RF 恰一约束。定义实际 CO=g+，要求 g 无环；RA 监视器使用 g+ 代替 CO，
故原禁止词 (s|r)+(r|c|R c+)* 中仅把 c 解释为 g 的生成边，语言形式不变。
另一个 c+ 无环监视器保留，Q;c+ 绑定监视器删除。

引理 10.1。完成全部原始 CO 选择后，如果 g 无环，则 g+ 是每地址严格全序，
并且其方向与所有原始 CO 标签完全一致。
证明：任意两个同地址写，要么在 L 中可比，此时 cover(L) 有对应路径；要么
对应未决原始比较已向 g 加入一个方向。因此每对写在 g+ 中可比。无环排除
反身及双向可达，传递性由闭包给出。若闭包逆转某标签方向，该标签生成边
或 L 路径与反向路径构成环，矛盾。初始化最小性也由 L 的初始化前序保存。

引理 10.2。新旧构造的原始 RF/CO 投影相同。
证明：任一合法 RA 赋值包含 L，选择其全部未决 CO 方向构造 g；g 是其 CO
子关系，且由引理10.1所有比较均被覆盖，因此 g+=CO，RF 与 HB 也不变，
所有监视器接受。反向由引理10.1，新构造得到严格全序 CO，RA 监视器精确
检验 hb/eco，并与原始标签一致，故是同一个合同中的合法赋值。

定理 10.3。新构造保持原始投影、任意原始部分赋值下的全部支持与支持 CNF
的传播完备性。证明：引理10.2给出执行集合等价；每个未决原始位仍只赋值
一次，已认证常量保持原始编号。所有生成边都是固定候选组中的永久选择；
按最后可能关联组遗忘，原联合乘积可达摘要的精确性证明直接适用，前后向
支持及 CNF 证明也不变。这里 g 不解释为会被未来写插入打断的相邻关系，
故没有违反旧相邻写定理要求“最终相邻见证不可撤销”的前提。

成本边界：该变化消除了辅助相邻写选择和绑定监视器，但不保证所有输入都
变成多项式，也不保证前沿更小；直接比较可能产生稠密候选图。必须记录新
分解的实际前沿和中间状态，不沿用原 F 的宽度统计。它是通用 RA 构造的
另一种实现，命名为 F-direct-co，不冒充单地址特化 D 或已有通用 BDD 基线。

在本实现的紧凑监视器中，原状态数为8、2、5，新构造只保留8、2。设新分解的
实际前沿为k，候选组数为M，则联合矩阵及RF度计数的保守摘要上界为
  S <= 2^(68 k^2 + O(k))，图规模 O(M S)，另计原始变量输出和局部闭包成本。
这是原界中删除绑定监视器及相邻度约束后的直接计数，不是新的多项式保证。
只有在比较双方具有同样k时才可直接比较矩阵项93k^2与68k^2；不能据此推出
新算法对所有实例更快。实测状态减少也不能当成精确商图的最小性证明。

11. 更强的完整 SAT 对照

对每个原始部分赋值 alpha，先运行 SAT 的原生单位传播。若冲突则无补全；
否则其返回的原始文字都是 F and alpha 的后果，可从反模型候选中可靠删除。
然后仍检查 SAT，并对余下位用反模型同时确认两值支持或反证强制性。
只有全局后果可跨查询缓存；第一条空假设完整查询提取的全局后果覆盖库不
返回的根层 trail。故该优化保持完整支持合同，而非将单位传播当成完整算法。
实验同时计入原生 UP 与后续搜索成本，完整保留搜索次数及结果摘要。
另一固定策略把尚未解决位的 phase 设为参考模型的反值，争取一次反模型
覆盖更多双值支持；已解决位偏向参考值。这些只是 solver.set_phases 偏好，
所有可满足性约束、反证步骤及终止条件保持，因此正确性与完备性不变。

12. 符号基线的构造次序

coherence-first 版本仅改变合取顺序：先加入 RF 恰一、HB 无环和四类
coherence，再加入 CO 传递性。最终 Boolean 函数相同；中间 BDD 可以小得多。
semantic_order 只按事件在输入中的顺序排列初始 CO 变量，避免字符串编号
将第10个事件排到第2个之前；随后仍启用 CUDD 的动态重排。变量身份及查询
编号不变。因此这两项优化保持全部原始投影和支持，不使用我们的历史摘要。
它们作为单独基线活动重跑所有34个配置，旧构造及其失败结果完整保留。
每对写的两个方向是同一位的互补，因此一个无序三元组的六条传递性蕴含
实际只有两条不同子句，分别排除两个方向的三环。新版本只合取这两条，
避免重复三次；仍然精确表示所有原传递性蕴含，不依赖摘要或执行枚举。

将逐配置最好的已测 BDD/SAT 策略作比较，只是给基线一个不收费的策略选择
优势；它不是已经实现的在线选择算法，也不能据这些数据推断新实例的最优策略。
