后续端口摘要：算法阶段交付
2026-10-15

本轮完成了一个通用固定事件 RA 构造改进及其数学证明稿，并在服务器复核实现。
当前重点是减少构造工作量；没有重跑完整论文评测，也没有加入新的实例族。

1. 算法与证明的实际增量

F-direct-co 原来按事件保留所有自动机状态之间的可达信息。新 F-ports 根据
后续全部候选关系边的入/出关联位置，直接保留“未来入口 × 未来出口”的摘要。
四状态 RA 自动机使用普通路径 R 与恰一标记路径 T 联合保存禁止性检查，避免
起点已遗忘后漏检。CO 无环监视器用一份普通闭包。不同关系、度计数、原始
选择的相关性没有拆开；在生成新层时立即按联合摘要合并，不先构造大图。

docs/FUTURE_PORT_THEOREMS.zh.txt 给出：
- 正则禁止游走与恰一标记游走的等价；
- 可从候选关系扫描得到的端口条件及其更新/投影封闭性；
- 同摘要历史的后缀等价、原始 RF/CO 投影与完备传播保持；
- 以 rho=2|I_RA||O_RA|+|I_CO||O_CO| 为参数的构造界；
- 相同选择序下逐层状态数/候选尝试数不增的保证；
- 一个旧完整闭包构造指数、新端口构造线性的通用无环约束族。
最后一项不是新的 RA 实验族，也不是任意 BDD/SAT 或所有有界历史方法的下界。
活跃端点与图消元的一般思想已有先例，本稿没有声称首次提出这些通用原理。

2. 现有实例上的开发复核

同一服务器、相同候选组序、相同直接 CO 语义、相同原始查询流；每项只运行一次，
固定同一 CPU，独立进程，4 GiB地址空间。下面时间只作开发记录，不作正式速度比。

阶段       旧/新状态             旧/新候选尝试         旧/新构造秒
1          105 / 78              128 / 91              0.01550 / 0.00474
2          2,770 / 1,766         3,886 / 2,326         0.90195 / 0.10993
3          29,449 / 10,379       37,062 / 13,218       16.82200 / 0.74186

三阶段状态减少64.8%，候选尝试减少64.3%。每一层状态数不增的关系均通过核验。
运行时间改善还包含更小的乘积矩阵及确定性监视器更新缓存，不能全部归因于状态
合并；完整机制剖析和基线计时按计划留待最终统一评测。

服务器40项测试全部通过。新增测试覆盖：独立密集 R/R;B;R 对照、两个标记不能
被错误串联、起点遗忘后闭环、小实例全部2,187个原始部分赋值、混合RA随机输入、
支持CNF和完整见证。现有三组流水线共1,536个查询位置的新旧完整答案摘要相同。
这些查询位置不声称全都不同；小实例枚举只用于测试，生产构造没有枚举步骤。
原数学证明仍需独立审查，不把测试一致当作证明认证。服务器未发生物理内存不足。

结果：results/ports_development/ 保存所有单次逐查询计时、答案摘要、环境源码
摘要、逐层状态与测试输出；没有写入/替换 results/paper 的冻结评测数据。

3. 编译收益结论

已单独从旧正式数据逐前缀重新分析：两生产者每个8/32/64写的显式 D，相对
两种加强SAT策略的有利事后包络，分别从20/11/8次查询起到512次持续累计更快。
旧通用 F-direct-co 的1/2/3阶段流水线在1..512的所有前缀都没有胜过加强SAT或
已测关系BDD。重复IRIW的轻微最终胜出也不代表稳定、早期或相对BDD的收益。

因此判断条件是后续完整查询的累计节省能否抵消识别/构造/初始化开销，而不是
完备性本身或查询次数本身。具体公式、复用前提、数据索引和边界见
docs/COMPILATION_ECONOMICS.zh.txt。新 F-ports 的正式摊销曲线尚未测量，不能
套用旧算法阈值或将本次单次开发结果混入旧5次中位数。

4. 使用和复核

  python -m wmcheck.ra_cli --family pipeline --size 3 --algorithm frontier-ports
  python -m unittest tests.test_port_summaries -v
  python -m unittest discover -s tests -v

Linux服务器上复现开发活动（需要已解包到 results/paper 的原始输入）：
  python experiments/ports_development.py
旧自动分派与旧算法选项保持，可显式选择本次新实现。

后续工作是针对稳定算法选择实际交互实例族、统一记录性能机制并运行正式比较。
当前改进没有扩大RA模型语义范围，没有使一般输入变成多项式，也没有证明已解决
所有通用性能差距。当前理论/算法增量是否足够原创与重要仍需独立文献及同行审查。
